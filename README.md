# ZEROCODE

ZEROCODE is an adaptive emergency work-resolution protocol.

Core principle:

> ZERO is hard on direction and fluid on method.

ZEROCODE is designed to survive changes in models, tools, code, runtimes, frameworks, and infrastructure without silently changing approved objectives, hardlines, or canonical meaning.

## Separation

- ZEROCODE is experimental and operational.
- PYXIS is the future auditable resolver architecture.
- NARA is protected and is not created, redefined, cloned, or deleted by ZEROCODE.
- Supabase is not part of the ZEROCODE baseline.
- Project/client data and credentials must not be committed to this public repository.
