# ZEROCODE Adapter Boundary

ZERO is independent of model/provider/runtime.

Current adapters:
- GPT Web — reasoning/research/review
- Codex Desktop — execution/build
- OpenClaw @ Zeabur — utility/research/long-running work
- Google Drive Work Mode — artifact exchange
- GitHub — versioned protocol/config/code
- InsForge — candidate backend/control adapter

## Replacement rule

An adapter may be changed without canonical approval when mission, hardlines, and approved output standards remain intact.

If an adapter change requires changing canonical meaning, project hardlines, approved map/document standards, NARA, or canonical PYXIS/AOA semantics, stop and request Luqman approval.

Supabase is not a ZEROCODE adapter target or required dependency.
