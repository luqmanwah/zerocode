# ZEROCODE Quality Gate v0.1

No substantial output is FINAL until it passes the relevant checks below.

## Universal checks

1. OBJECTIVE MATCH
   - Does the result solve the actual task?

2. HARDLINE CHECK
   - Did the result preserve approved constraints and standards?

3. SOURCE / INPUT CHECK
   - Are factual claims grounded in the required source/input?
   - Are unknowns clearly marked?

4. FORMAT CHECK
   - Does the output match the approved format/template when one exists?

5. COMPLETENESS CHECK
   - Are required sections, fields, tables, maps, attachments, or deliverables present?

6. CONSISTENCY CHECK
   - Does the result contradict known approved context?

7. ARTIFACT CHECK
   - Does the file open and function correctly?
   - Is the correct version saved in the correct location?

## Failure behavior

If a check fails:
- do not call the task done,
- repair the smallest failing part,
- re-run the relevant check,
- do not redesign unrelated infrastructure.

## Professional documents

Use the approved project/document/map standards as hardlines.
Do not let a newer model silently redesign structure, tone, map composition, numbering, or evidence handling.

## FINAL means

Correct enough to hand over or use operationally, not merely generated.
