# ZEROCODE Production Bootstrap

ZEROCODE will not expand infrastructure before proving one real end-to-end job.

## Phase 1 — prove the line

Use:
- GPT Web
- Codex Desktop
- existing OpenClaw only if the task needs long-running research
- Google Drive
- GitHub

Do not add:
- new database
- new queue
- new vector index
- new agent framework
- new dashboard
- new paid integration

## Test

Choose one real delayed professional task.

ZERO must:
1. understand it,
2. identify hardlines,
3. select the smallest route,
4. execute,
5. verify,
6. return a usable result,
7. record only the operational lesson that matters.

## Promotion rule

Only after the first real task succeeds may we ask:
- What was actually slow?
- What repeated manual step should be automated?
- Did we need InsForge?
- Did OpenClaw materially help?
- Did Codex need a gateway?

Infrastructure is added only in response to measured friction.
